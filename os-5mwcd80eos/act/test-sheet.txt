# act 0.5: on-site show test (14 minutes)

For Markus, before a show: the iPad with act, the Mac with act Receiver, one USB-C Ethernet adapter
on each. Do the items in order and mark **Pass** or **Fail**. Any Fail: take a screenshot of act's
Network screen (tap the Network widget) and of act Receiver's window, and note the time.

The 2-hour run (item 9) starts in the middle and ends after the sheet. Leave it playing.

## Set up (2 min)

| # | Do | Pass when | Pass / Fail |
|---|---|---|---|
| 1 | Cable the iPad and the Mac to the show switch (or to each other). Settings › Interface: **Automatic** on both. | act's Network widget shows **Interface: Ethernet · en…**. act Receiver's **In Use** shows the USB adapter's name, not Wi-Fi. | |
| 2 | Open act Receiver, then act. In act Receiver › Streams, click your iPad's program once (it is remembered: from then on only that program is played, never another act on the network). | Receiver window: **Connected**, **16 ch · 2 streams**. act: **Sending · 16 ch**, **Clock: PTP**, **Receiver: Connected**. | |
| 3 | Check **Buffer** in act Receiver. | **Wired, 2 ms** (it picks Wi-Fi Safe, 50 ms, only on Wi-Fi). | |
| 4 | Check the venue settings match the house network (act › Settings › Venue Network; act Receiver › Connection). Ask the network tech for: the PTP domain, the QoS scheme (AES67, Dante before 4.2, RAVENNA), and a block of 5 multicast addresses. | Both apps show the same **PTP Domain** and **QoS**; act's **Uses** shows the 5 addresses you were given. | |

## Play (3 min)

| # | Do | Pass when | Pass / Fail |
|---|---|---|---|
| 5 | Play a song with 8 stereo stems. Watch act Receiver's meters. | All 16 meters move. Lost, Late, Dropouts stay **0**. | |
| 6 | Let the song run into the next one (Continue on). | The change is gapless and the counters stay **0**. | |
| 7 | Hold **Talk** on the iPad and speak; then hold **Hold to Talk** on the Mac. First press on each asks for the microphone: allow, press again. | The Mac hears the iPad on the chosen output pair; the iPad hears the Mac in its headphones. The other side's dot lights while talking. | |
| 8 | Tap each pad. If the iPad has a trackpad or mouse: scroll the setlist and the mixer with it. | Each pad fires at the touch (no wait for release). Scrolling works and act keeps running. | |

## Vocals (2 min)

| # | Do | Pass when | Pass / Fail |
|---|---|---|---|
| V1 | Tap the Vocal 1 widget. Stream: the stage box (or console) stream; Channel: the singer's input. Same for Vocal 2. | The widget shows **stream · channel**; its In meter moves when the singer sings. | |
| V2 | Add Effect › All Pitch (or the effect you use) on Vocal 1; tap it to open its own view and set key and scale. | Out meter moves; act Receiver's **Vocals** section shows both meters moving, Lost · Dropouts **0 · 0**. | |
| V3 | Unplug the stage box stream for 5 s (or pick Local Input Only), with Use When Stream Is Missing on. | The vocal carries on from the iPad's audio interface (status **Input 1 · Fallback**) and goes back to the stream by itself. | |

## Mixer, pads, search (2 min)

| # | Do | Pass when | Pass / Fail |
|---|---|---|---|
| M1 | Play. In the Mixer, drag anywhere on a stem's bar, slowly then fast. Double-tap the bar. Tap a stem's name; hold another's name. | The white line moves with your finger from where it was (slow = fine); a tick at 0 dB and at the bottom; double-tap: 0 dB and back; tap: muted (white), hold: solo (yellow). Meters fall smoothly, no jumps. | |
| M2 | Edit › + › FX Pads › Add. Edit, tap an FX pad, Choose Sample…, Plays: Loop, Quantise: Bar (set the song tempo). Done. Tap the pad during the song. | The pad starts on the next bar (yellow outline while it waits), loops, stops on the next tap. act Receiver's FX meters move. | |
| M3 | Type part of a song or stem name in the Setlist's search. | The list filters as you type; clear it with ×. | |
| M4 | Lock the iPad for 2 minutes during a song (Settings › Background › Lock Screen Controls on). Use play/pause on the lock screen. | act Receiver hears the whole time (Dropouts unchanged); the lock screen shows the song and controls it. Swiping act away in the app switcher stops everything: never do that during a show. | |

## Faults (4 min)

| # | Do | Pass when | Pass / Fail |
|---|---|---|---|
| 9 | Start the 2-hour run now: Loop on (Settings), Play, leave it. | (Checked at the end, item 13.) | |
| 10 | **Cable pull:** pull the iPad's Ethernet for 10 s, plug it back. | During: act shows **No Network · Waiting** (or moves to Wi-Fi if it has one). After: **Sending**, **Receiver: Connected** again **within 5 s**, the song still playing where it should be. | |
| 11 | **Lock:** press the iPad's top button for 30 s, unlock. | The Mac kept playing the whole time (no gap on the meters, Dropouts unchanged). | |
| 12 | **Call:** have someone call or FaceTime the iPad. Decline from the banner. Then Siri ("Hey Siri, what time is it?"). | The Mac keeps playing through both. Network › Talkback › Audio shows **Interrupted** during, **Running** after, by itself. | |

Before the show: turn on **Do Not Disturb** (Focus) on the iPad and keep it charging. Wi-Fi can stay
off; the wired adapter works in Airplane mode. If a call is *answered*, iPadOS may stop act until
you return to it: then it resumes on its own within a few seconds (item 10's recovery).

## After 2 hours (1 min)

| # | Do | Pass when | Pass / Fail |
|---|---|---|---|
| 13 | Read act Receiver's Buffer section and act's Network › Receiver. | **Dropouts 0** and **Lost 0** apart from the cable pull in item 10 (that pull may add 1 dropout). Clock still **PTP**, Leader/Locked. No audible clicks noted. | |

Send the sheet back with the screenshots of any Fail.
